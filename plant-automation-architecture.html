01

Overview

The rig replaces one manual task — hand-misting and hand-feeding 10 pots on a fixed clock — with sensor-driven timing, set up and watched from a phone or laptop rather than the OLED alone. The web app and its database live on Railway from the very first unit, so scaling to a greenhouse fleet later is a matter of pairing more units, not rebuilding the backend.

Growing environment

Parakandeniya, Kadawatha — lowland wet zone, Sri Lanka. Ambient conditions (70%–85% RH, 26–32°C) sit close to what epiphytic Dendrobium hybrids want, which is why the automation logic leans on humidity and temperature rather than a soil signal — there is no soil.

04

Hardware

There's no soil to sense here, so the soil moisture sensor from the generic design drops out entirely — humidity and canopy temperature take over as the mist trigger. Water and feed are two independent source lines (plain water reservoir, weekly feed reservoir) that share one fogging manifold, so the same 4-channel relay board now maps to pump + valve, twice rather than four unrelated outputs.

05

Firmware

Seven modules on the ESP32, each with one job. The rule engine is the only one that makes decisions — everything else reads, writes, or executes.

Sensor Manager

Polls DHT22/BME280 and the rain sensor; debounces and averages readings.

poll interval: 60s

Rule Engine / Scheduler

Evaluates humidity/temp thresholds, rain lockout, and the AM window; tracks the 5-week feed phase and the 14-day fungicide reminder.

see Control loop →

Actuator Controller

Drives the 4 relay channels with interlocks — a valve never opens without its own pump, and the two lines never run at the same time.

enforces min/max run time

Config Store

Caches the last config pulled from the cloud — thresholds, AM window, feed-rotation state — so the unit keeps running if Railway or Wi-Fi drops.

LittleFS · /config.json, synced

Cloud Sync Client

Pulls schedule/config from the Railway app on an interval, pushes sensor readings and event logs back.

see Web application →

Display Driver

Rotates the OLED between live readings, sync status, and Wi-Fi status.

I2C · 128×32

Wi-Fi & Pairing Manager

Connects to saved credentials, then authenticates this unit to the Railway app with its device key; falls back to a setup access point if unconfigured.

captive portal on first boot
06

Control loop

One cycle every 60 seconds, gated to the 6:30–8:00 AM window plus threshold-triggered top-ups through the day — never after dusk, since a wet crown overnight is how rot starts. On a day flagged for feeding, "actuate" is the two-step sequence: water line runs, firmware waits 15 minutes, then the feed line runs. Fungicide never actuates automatically — the WP formulation can clog a 30-µm nozzle, so day 14 just raises a reminder on the OLED and web UI for a hand spray.

07

Web application

You log into the Railway-hosted app, not the ESP32 — the unit itself has no UI beyond its OLED. One important split: the cloud app configures and records, the unit decides and acts. Each unit pulls its schedule down and keeps misting on that last-synced copy even if Wi-Fi or Railway is unreachable; it pushes readings and events back up whenever it can. Going from 1 unit to a greenhouse fleet later means pairing more units against the same app — the app doesn't change shape.

Data & storage

Postgres on Railway is the source of truth; the ESP32 keeps a read-only cached copy of its own config so it can act without a live connection. The rotation is computed from feed_start_date rather than hand-toggled each week, so a reboot — or a week offline — doesn't lose the phase.

Open items

Before wiring up the bench

The soil moisture sensor from the generic design is gone for good — orchids in charcoal have no soil to sense. What's left, in order of what blocks the build:
  • Swap the SSR for a DC-rated relay or MOSFET module.The OMRON G3MB-202P in the cart is an AC solid-state relay — it can't reliably switch the 12V DC pumps or valves.
  • Verify the misting kit's nozzles are actually 30-micron brass, and add an inline filter.Generic mist-kit nozzles are usually coarser than fogging spec; a clogged or too-coarse nozzle wets the crown instead of fogging it, which is the rot risk the shade net and roof are already there to prevent.
  • Order a 12V peristaltic dosing pump and a check valve for the feed line.Nothing currently pushes the 250 mL weekly feed mix through the manifold, and without a check valve it can siphon back into the plain-water tank.
  • Mount the humidity/temp sensor 1.5 ft above canopy and the rain sensor at 45° outside.Both placements are load-bearing for the trigger logic, not cosmetic — a sensor at the wrong height or angle reads the wrong thing and mists (or doesn't) at the wrong time.
  • Keep fungicide spraying manual.Oasis Captan is a wettable powder — even well-mixed, particulate residue risks clogging a 30-µm nozzle. The firmware surfaces a reminder instead of automating the spray.
  • Confirm the Kadawatha site has internet-carrying Wi-Fi, not just a LAN.Moving the app to Railway from day one means the unit needs an outbound path to the internet, not only local network access — worth checking before the unit is mounted somewhere the router doesn't reach.
